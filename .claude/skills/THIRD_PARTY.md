## Claude Code Game Studios

The skills dreadhollow-balance, dreadhollow-feedback, dreadhollow-release and dreadhollow-liveops are written for
this game, with method and structure adapted (not copied) from **Claude Code Game Studios**
(https://github.com/Donchitos/Claude-Code-Game-Studios): its balance-check, bug-triage, launch-checklist /
release-checklist skills and its live-ops-designer agent. MIT License, Copyright (c) 2026 Donchitos.
The template itself (agents, hooks, rules, project scaffolding) is not installed: it targets new projects in
Unity, Godot or Unreal and would replace this repository's own settings and workflow.
